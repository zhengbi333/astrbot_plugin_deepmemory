# alpha-0.45（2026-08-08）

## 修复

- **DS / 证毕按钮时机**：改为「n 条气泡逐条轮换（点击一次一条）→ 显示完最后一条后的**下一次点击**才出现按钮」的循环（DS：气泡×4 → 「饭饭」按钮；证毕：气泡×9 → 「想听听作者的话吗？」按钮），按钮出现后循环重置，继续气泡轮换。
- **气泡淡出**：新气泡出现时，同卡片上的旧气泡立即快速淡出（0.25s）再移除，不再遮挡。
- **气泡与按钮位置**：统一移动到人物卡**下方**（顶部尖角指向卡片）。
- **二氧化硫冲撞**：改为持续加速运动（每帧速度 ×1.045，设速度上限防飞出），始终有动力、越来越快，撞到视口边缘反弹。
