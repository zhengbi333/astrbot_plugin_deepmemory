# alpha-0.4（2026-08-07）

## 新增

- 新增「日志」标签页：
  - 查看插件运行时日志（尾部 N 行，支持 200/500/1000/2000 行）。
  - 按级别过滤（DEBUG / INFO / WARNING / ERROR），错误与警告高亮显示。
  - 自动刷新（10 秒）与手动刷新；清空全部日志文件。
  - 显示日志文件列表（名称 / 大小 / 修改时间）。
- 插件日志系统：
  - 日志写入数据目录 `logs/deepmemory.log`，单文件 5 MiB，最多 5 个滚动备份（磁盘上限约 30 MiB）。
  - 启动时自动清理超过 30 天的滚动备份。
  - 全部日志出口（main / page_api / service / retrieval）切换到插件专用 logger，控制台与文件双输出。
- 外观页新增「背景板颜色」：可自定义页面底色（独立于明暗主题），图片启用时覆盖底色。

## 修复

- 背景图片上传后页面不显示、重载后无图：
  - 背景图渲染从 CSS 变量内 `url()` 改为独立背景层 DOM（`#bg-layer`），由 JS 直接设置 `backgroundImage`，规避 CSS 变量中 `url()` 的兼容性问题。
  - 上传成功后自动勾选「启用背景」并立即生效。
  - 预览区改为「已上传即显示预览」，不再受启用开关影响。
- 透明度 / 模糊度滑杆两端无法拖满：为 range 增加 thumb 半径补偿（两端各 -8px），0 与 100 现在可拖到视觉端点。

## 说明

- 日志文件在 Windows 下被文件句柄占用，清空前会先关闭句柄再重建。
