# alpha-0.24（2026-08-08）

## 修复

- **开关（toggle）设置保存无效**：
  - 根因（前端）：开关点击时用 `set-${t.dataset.key}` 查找关联的隐藏输入框，但 `dataset.key` 是点号形式（`module.key`），输入框 id 是下划线形式（`set-module_key`），查找失败导致隐藏值从不更新——保存时读取的仍是旧值，视觉上开关有动画但"保存无效果"。
  - 修复：查找 id 时把点号替换为下划线，与输入框 id 对齐。
  - 数值类输入框 id 本就匹配，因此此前"数值可改、开关不可改"的症状与本次根因完全吻合。
