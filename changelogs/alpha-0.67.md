# alpha-0.67（2026-08-08）

## 变更

- **修复 Bot 短回复不进时间线（轮数停滞的最终根因）**：
  - 根因：Bot 回复捕获复用用户消息的最短字数阈值（`capture_min_chars`，默认 2），
    单字符回复（如「1」「2」）与极短回复（「好的」等）被过滤丢弃 → 时间线只有用户消息 →
    连续用户段合并、轮数停滞 → 达标后没有 Bot 回复触发总结；
  - 修复：Bot 回复使用独立阈值 `capture.bot_min_chars`（默认 1：任何非空回复都记录；
    仅空回复丢弃），设置页可调；用户消息阈值不变。
- 配合 alpha-0.65/0.66 的后台扫描循环与防重超时保护，达标会话将稳定自动总结。

## 说明

- 专项验证：Bot 单字符回复进入时间线、空回复仍过滤；完整回归通过。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_deepmemory_alpha-0.67`。
