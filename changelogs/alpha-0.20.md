# alpha-0.20（2026-08-08）

## 修复

- **设置保存后刷新仍显示旧值（多实例一致性）**：
  - 根因：AstrBot 重载插件时可能出现多个插件实例并存（日志中「已加载/已启动」多次出现），Web API 请求可能命中内存配置仍为旧值的实例，因此「保存成功但刷新后页面还是旧值」。
  - 修复：`config_values`（设置页读取配置）每次调用前强制从磁盘刷新运行时配置——磁盘文件是实例间共享的，无论请求命中哪个实例都能读到最新值。
  - 新增多实例一致性测试：实例 A 保存 → 实例 B 读取直接得到新值，验证通过。

## 说明

- 深忆 WebUI 的「设置」页与 AstrBot 自己的插件配置页（插件管理 → 配置）共用同一个配置文件；请在**其中一个**界面修改配置，避免互相覆盖（例如：在 AstrBot 插件配置页保存过一次后，WebUI 设置页之前保存的值会被覆盖）。
