# alpha-0.38（2026-08-08）

## 变更

- **列表页条数上限提示**（防止数据量大后"划不到头"）：
  - 时间线页：显示「时间线共 N 条 · 显示最近 100 条」。
  - 记忆库：分页行显示「每页 30 条 · 记忆库共 N 条」。
  - 导入导出手动记忆列表：显示「记忆库共 N 条 · 显示最近 30 条（完整管理请用记忆库页）」。
  - 用户列表：说明显示上限 300 条。
  - 后端各列表接口本就带有硬上限（记忆/时间线 ≤ 200、用户 ≤ 500），不会因数据量过大拖垮页面。

## 说明

- 人格归属：已确认你的「测试」配置文件（`data/config/abconf_*.json`）中 `default_personality: "测试人格"`，插件在会话未绑定人格时会跟随该配置文件的默认人格，无需额外会话绑定（AStrBot 会话绑定人格入口若在界面不可见，可用全局默认人格即可）。
- 时间线中的旧退群消息在早前版本已被清理策略删除；新捕获的系统通知（退群等）会显示并标记「系统通知」，不计入未总结。
