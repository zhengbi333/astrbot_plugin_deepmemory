# alpha-0.72（2026-08-08）

## 变更

- **导出兼容 AstrBot Launcher 内置浏览器**：
  - 现象：Launcher 内置浏览器（WebView）无法触发文件下载，且无法打开外部链接（GitHub 等），
    属桌面壳限制，插件页面内无法修复外链跳转；
  - 修复：新增 `POST /export/archive`（生成档案并返回文件路径），导出按钮先生成档案并**在页面提示
    完整文件路径**（用户可直接从文件管理器取用），普通浏览器环境仍继续触发自动下载；
  - Launcher 无法打开外部链接的说明：请复制链接到系统浏览器打开（插件页面内的外链行为受桌面壳约束）。
