# alpha-0.32（2026-08-08）

## 变更

- **身份记忆拟人化**：
  - 此前自动沉淀的身份记忆措辞机器化（「用户X（平台ID）是我正在陪伴的对话伙伴」），会让模型把用户身份当作系统已知量。
  - 现在改为像人的共同经历叙述：「X 告诉过我他的名字，我平时都这么叫他，我们互相认识。」；平台 ID、平台名等机器信息只写入 metadata，不进入记忆正文。
  - 多用户场景下身份记忆按「用户 + 人格」隔离，各自独立；每轮注入包仍会声明当前对话者，不会混淆。
- 已清理库中旧版机器化身份记忆（1 条），下次对话自动沉淀拟人化新版。

## 说明

- 阶段总结本身只生成一条记忆（自 alpha-0.16 起）；此前看到的第二条是自动身份记忆，现已拟人化。
- 拟人化目标下，记忆内容与注入包均以双方称呼展开（如「用户告诉过我他的名字」），不再出现「用户/机器人」类通称。
