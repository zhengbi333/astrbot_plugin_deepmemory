# alpha-0.3（2026-08-07）

## 新增

- 新增「外观」选项卡：
  - 6 套预设配色主题（紫罗兰 / 青蓝 / 粉 / 绿 / 琥珀 / 靛），支持自定义主色 / 辅色（取色器）。
  - 背景图片上传（≤ 8 MiB，PNG/JPG/GIF/WebP/BMP），保存到数据目录 `backgrounds/`，以 data URL 方式渲染（受限 iframe 无法直连静态资源）。
  - 背景透明度（0-100%）与背景模糊（0-30px）滑杆调节。
  - 启用背景后卡片 / 侧边栏 / 弹窗自动切换玻璃拟态（半透明 + 背景模糊）。
  - 外观配置持久化到数据目录 `appearance.json`；支持保存与恢复默认。
- 新增更新日志目录 `changelogs/`，每个版本一个 Markdown 文件（alpha-0.1 起补录）。

## 修复

- 移除左上角品牌 logo 图片（受限 iframe 下图片加载失败），品牌区仅保留文字。

## 说明

- 背景图片通过 `GET /appearance` 返回 base64 data URL，首次读取后内存缓存。
- 玻璃效果依赖浏览器 `backdrop-filter` 支持；不支持时回退为半透明背景色。
