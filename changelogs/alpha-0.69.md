# alpha-0.69（2026-08-08）

## 变更

- **嵌入调用超时放宽**（修复偶发「嵌入调用超时」告警）：
  - 现象：Provider 连通性测试稳定（<200ms），但运行时偶发 `嵌入调用超时: provider=openai_embedding`；
  - 原因：SDK 在瞬时网络波动/接口限流时自动重试（指数退避），重试窗口可超过原 5 秒阈值；
    测试是单次调用，不反映持续调用下的波动；
  - 修复：`retrieval.embedding_timeout_ms` 默认 5000 → **15000**（覆盖 SDK 重试窗口）；
    设置页提示同步更新；
  - 自愈说明：超时未向量化的记忆会在后台背填循环（每 5 分钟）自动重试，无需人工干预。
