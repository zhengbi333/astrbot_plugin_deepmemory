# alpha-0.25（2026-08-08）

## 变更

- **移除备用配置文件机制**（`runtime_config.json`）：此前它是配置混淆的来源之一（旧残留覆盖过新值）。现在主配置文件（AstrBot 配置目录 `data/config/astrbot_plugin_deepmemory_config.json`）是唯一权威来源；写入失败会明确报错（页面提示 + 日志 `保存主配置文件失败`）。
- **配置加载日志**：插件每次从磁盘加载配置时记录 `运行时配置已加载: source=... embedding_enabled=...`，可在日志页确认读取来源与值。
- **诊断卡片新增「插件内存值」**：区分「磁盘文件值 / 插件读取值（页面渲染）/ 插件内存值」三个环节，异常时可直接定位是哪一环。

## 验证

- 真实数据目录复现脚本确认：磁盘 `false`（用户保存值）→ 插件读取 `false`，`0.33`/`0.54` 等用户修改全部生效——保存链路自洽。
- 此前「磁盘 true / 读取 false」为旧实例（插件重载历史残留）或旧页面缓存所致；请重载插件并强制刷新浏览器（Ctrl+F5）后复查。
