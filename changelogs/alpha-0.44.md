# alpha-0.44（2026-08-08）

## 修复

- **悬停荧光不明显**：改为「白框 + 白色光晕脉动」动画（hover 时边框变白、光晕 1.6s 呼吸式增强），亮色/暗色主题下均可见。
- **气泡淡出**：气泡显示结束后 0.25s 快速淡出上滑消失，下一条衔接时不会遮挡。
- **DS「饭饭」跳转**：受限 iframe 无法直接跳转外部站点（且无返回），改为弹窗提供充值链接（可复制/尝试新标签页打开），不再丢失当前页面。
- **证毕点击逻辑**：改为逐句轮换气泡（点击一次显示一句，按顺序循环）；播放完整一轮（9 句）后再次点击才浮现「想听听作者的话吗？」按钮；解锁「作者的话」后回到页面点击仍正常轮换气泡，不会直接弹按钮。
- **二氧化硫冲撞**：
  - 运动范围改为整个视口（此前受 flex 容器高度限制只能横向移动）。
  - 冲撞期间逐帧检测与各目标元素（其他人物卡、条幅、侧边栏标签）的真实矩形相交，相交即触发掉落/碎裂（0.8s 后恢复），并保留随机兜底。
