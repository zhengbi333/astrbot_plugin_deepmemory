# alpha-0.41（2026-08-08）

## 变更

- **分页显示「第 x/n 页」**：时间线、用户列表、手动记忆列表、记忆库四个分页均显示总页数（后端 `timeline` / `users` / `memories` 接口新增 `total` 返回，与列表同条件计数）。
- **换页不丢位置**：点击上一页/下一页后自动滚动到分页控件位置（视口内上方留白 90px），无需再手动下滑找按钮；首次进入页面不触发滚动。
- **特别鸣谢提示条**：文案改为「这里是只会用AI写插件的屑创作者，和他参与测试的朋友们~！」，字号加大至 18px。
