# alpha-0.6（2026-08-07）

## 修复

- **明暗模式「跟随系统」失效**：此前 `auto` 模式读取的是本页手动设置过的 `data-theme`（被亮色/暗色选择污染），切回跟随后不会还原。现在 `auto` 模式优先读取父页面 bridge context 的 `isDark` 真实主题，并同步还原 `data-theme`。
- **配色主题按钮失效（一直紫罗兰）**：根因是保存外观时把取色器的当前值写入了 `primary/accent`，导致「自定义覆盖」永远生效、主题切换被覆盖。现在：
  - 点击主题卡会清除主色/辅色/背景板颜色的自定义覆盖，回到跟随主题。
  - 颜色取色器只在用户手动操作时才写入覆盖；拖动透明度/模糊度滑杆不再误写颜色覆盖。
  - 保存时从当前状态读取（空 = 跟随主题）。
- **启用背景图后卡顿（取色器不跟手）**：
  - 背景图以 base64 data URL 渲染，此前每次拖动取色器都会重新赋值 `backgroundImage` 导致反复解码大图。现在仅在 URL 变化时重设（缓存比对）。
  - 收窄玻璃模糊范围：`backdrop-filter` 只作用于卡片/侧边栏/弹窗/设置模块等大容器，输入框、下拉、小标签不再参与模糊（大量模糊层是主要性能杀手）。
  - 背景层增加合成层提升（`translateZ(0)`），减少重绘。

## 说明

- 背景图片存放于 **AstrBot 数据目录**（非插件代码目录）：
  `<astrbot_data>/plugin_data/astrbot_plugin_deepmemory/backgrounds/bg.<ext>`
  外观配置在 `appearance.json`。更新插件版本时只同步插件代码目录，数据目录会被保留——这是刻意设计（升级不丢失背景图与外观设置）。如需删除背景图，可在外观页点「清除背景」，或手动删除 `backgrounds/` 目录下的文件。
