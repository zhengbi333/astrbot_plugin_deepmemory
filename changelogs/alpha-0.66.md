# alpha-0.66（2026-08-08）

## 变更

- **总结触发加固（轮数停滞/达标不总结）**：
  - 根因：达标会话的总结原本依赖「新 Bot 回复写入」触发；若 Bot 回复未被捕获进时间线
    （连续用户消息被合并计数），轮数停滞且永远等不到触发点；
  - 修复一：后台扫描循环（`summary.auto_scan_enabled`，默认开，间隔 60s 可配）——
    已达阈值的会话即使没有新消息也会被自动触发总结；
  - 修复二：总结防重集合加入 **TTL 超时保护**（5 分钟）——异常挂起的总结任务不再永久阻塞该会话；
  - 修复三：Bot 回复捕获增加日志（`捕获 Bot 回复`），便于确认回复是否进入时间线。
- 说明：以上修复自 alpha-0.65（扫描循环）与 alpha-0.66（TTL 保护）起生效，**请重载插件**；
  达标会话将在 60 秒内自动总结，轮数随之归零重新计数。
