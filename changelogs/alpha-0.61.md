# alpha-0.61（2026-08-08）

## 变更

- **私聊与群聊触发阈值分离**：
  - 私聊：按「对话轮」计数，阈值沿用 `summary.trigger_event_count`（默认 8）、最少事件 `min_events`（默认 4）；
  - 群聊：按「事件条数」计数（群聊消息彼此不构成轮），新增独立配置
    `summary.group_trigger_events`（默认 15）、`summary.group_min_events`（默认 6）；
  - 设置页「总结」模块可分别调整。
- **未总结统计按会话独立计算**：
  - 每个私聊会话独立计轮、每个群会话独立计事件（与触发逻辑一致），不再跨会话混算；
  - 面板新增：`待总结（私聊轮数）x/8`、`待总结（群聊事件）y/15` 分开展示，并显示**已达阈值的会话数**（私聊 a 个 / 群聊 b 个）；
  - 时间线页同步展示私聊/群聊两行进度与达标会话数；系统信息页同步更新。
- 说明：单个数字无法表达多会话进度，现以「合计 + 达标会话数」呈现；每个会话的明细可在时间线页按会话过滤查看。

## 说明

- 专项验证：多会话独立统计（2 群 + 2 私聊）、群聊独立阈值触发（10 条不触发 / 20 条触发）、完整回归通过。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_deepmemory_alpha-0.61`。
