# alpha-0.23（2026-08-08）

## 修复

- **配置读取仍为旧值（上一版遗漏的根因）**：
  - 用真实数据目录复现：磁盘主配置文件 `embedding_enabled: true`，但插件读到 `false`（且 `embedding_score_threshold: 0.33` 等旧值）——来源是插件数据目录下的**备用配置文件 `runtime_config.json`**：路径修复前的版本把用户保存的旧值写进了备用文件，而读取逻辑是「备用文件优先」，旧残留持续覆盖新主文件。
  - 修复：读取改为**主配置文件为权威来源**（AstrBot 配置目录）；备用文件仅在主文件缺失时作为恢复源，避免历史残留污染。
  - 已清理本机残留的旧 `runtime_config.json`（备份至临时目录）。
  - 真实环境复现脚本验证：磁盘 true → 插件读到 true；即使 AStrBot 传入旧配置值，文件值仍优先。

## 说明

- 设置页「配置诊断」卡片可直接对照磁盘值与插件读取值；本次修复后两者应一致。
