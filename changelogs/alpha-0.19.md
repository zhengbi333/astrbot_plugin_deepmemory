# alpha-0.19（2026-08-08）

## 修复

- **设置页保存后不生效/不刷新**：
  - 经全链路测试确认后端「保存 → 落盘 → 重载读取」正常；问题在于前端保存成功后未回显最新值（后端未返回新值、页面控件仍是旧快照）。
  - 修复：`config/module/update` 端点现在返回更新后的模块 values；前端保存成功后用返回值刷新 `settingsValues` 并重新渲染设置页，控件立即显示新值。
  - 说明：若此前在设置页保存后直接刷新页面仍显示旧值，请重载插件后再试（插件重载时会从磁盘配置恢复）。

## 变更

- **嵌入召回默认启用**：`retrieval.embedding_enabled` 默认值改为 `true`（未配置 Embedding Provider 时自动回退关键词检索，不影响使用）；已同步更新当前运行实例的配置文件。
