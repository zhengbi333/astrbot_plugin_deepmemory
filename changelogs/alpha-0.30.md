# alpha-0.30（2026-08-08）

## 修复

- **设置页底部出现 `|| '未找到配置'` 字面文本**：模板字符串闭合位置错误，`|| '<div class="empty">…</div>'` 被当作字面文本输出。已移入 `${...}` 表达式内部。

## 变更

- **设置页模块默认全部折叠**：进入设置页时所有模块收起，用户按需展开选择。
- **新增「动画设置」配置模块**（设置页底部）：
  - 启用界面动画（总开关）。
  - 动画时长（毫秒，150-300 建议）。
  - 选项卡切换动画：fade 淡入 / slide 上滑 / scale 缩放 / none。
  - 折叠展开动画：smooth 平滑 / none。
- **界面动画**：
  - 选项卡切换：页面内容淡入/上滑/缩放过渡（时长可调）。
  - 设置模块折叠展开：max-height + 透明度平滑过渡。
  - 侧边栏导航选中过渡。
  - 动画设置修改保存后立即生效。
