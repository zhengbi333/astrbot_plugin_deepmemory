# alpha-0.64（2026-08-08）

## 变更

- **身份记忆按「人格 + 用户 + 作用域」幂等沉淀**：
  - 此前私聊沉淀过身份记忆后，同一用户在群聊不再沉淀（全局按用户去重），
    开启隔离时群聊视角无法识别该用户；
  - 现在私聊与群聊各自沉淀一条（群聊按归属群），两侧都能正确认人；同作用域内仍幂等。
- **导入去重兜底（修复「重复导入显示导入 2 条」）**：
  - 根因：库中个别旧记录内容指纹为空（早期版本数据），导出后导入时指纹被重算，
    与库中空指纹记录无法匹配，导致这部分记录每次都被视为「新记忆」导入；
    又因 id 相同被 upsert 覆盖，表现为「显示导入 2 条但记忆库不变」；
  - 修复：指纹去重未命中时回退「同 id 且内容一致」判定为重复（跳过导入）；
    同 id 但内容不同则更换新 id 写入，避免误覆盖。

## 说明

- 专项验证：私聊/群聊同用户各沉淀一条且幂等；空指纹旧记录导出→导入被正确去重；
  完整回归通过。本机复现（正常数据导出→导入自己）为 imported=0 全部跳过。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_deepmemory_alpha-0.64`。
