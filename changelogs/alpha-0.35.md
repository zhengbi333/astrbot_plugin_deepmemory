# alpha-0.35（2026-08-08）

## 修复

- **待总结轮数被时间线残留卡住（1/3 不涨）**：
  - 根因：轮数仅按「同侧连续发言」计算。若时间线上有一段未总结的旧发言（如退群/系统消息残留或上次总结失败的残留），新对话的用户发言与它同侧连续，会被合并算作同一轮 → 轮数永远不涨。
  - 修复：轮数计算加入时间间隔切分——相邻事件间隔超过 30 分钟视为新的会话片段（新轮起点），旧残留与新对话自然分离。
  - 同时过滤群聊系统/状态通知（退群、入群、撤回、拍一拍等），不再进入时间线。
- **记忆总结人格归属为 default**：新增「人格解析链路」诊断（调试页）——展示最近一次「会话 → 当前对话 → 人格 ID」的解析过程与失败原因（如会话未选择对话、未配置人格等），便于确认 AstrBot 侧绑定情况；插件不做任何人格名写死（仅保留无人格时的通用兜底 "default"）。

## 变更

- **调试页新增「最近主链对话 Prompt」**：显示最近一次正常对话实际发送给 LLM 的完整内容（系统提示词 + 历史上下文 + 附加块 + 当前消息，注入前，完整未截断）；原「任务 Prompt（总结/衰减）」卡片保留。
- **每日减权日志增强**：执行后输出 `每日减权完成`，含处理条数、归档判定数、衰减率与最多 5 条变化示例（记忆 ID：旧值 → 新值（天数）），确认衰减确实生效。

## 说明

- 每日减权默认 0.5%/天（重要度 × 0.995/天），单日变化在小数后第三位；如需更明显的衰减可在设置中调大 `decay.daily_decay_rate_percent`。
- 人格归属问题：请先发一条消息，再到调试页查看「人格解析链路」；若显示 `persona_not_configured`，表示 AstrBot 会话未绑定人格（需在 AstrBot 侧为会话选择人格）。
