# alpha-0.54（2026-08-08）

## 变更

### 1. 群聊捕获/总结开关全面生效（修复 off 失效）
- 此前 `capture.group_capture_mode=off` 只能拦截「群消息过滤器」路径，群内 @Bot 走主链时会绕过开关照常捕获并触发总结。现在：
  - 主链路径（`handle_llm_request`）按开关捕获用户消息；
  - Bot 回复捕获（`handle_llm_response`）同样按开关；
  - 身份记忆沉淀（`ensure_identity_memory`）内置开关守卫，off 时群聊不再沉淀任何记忆；
  - 私聊不受群聊开关影响。

### 2. 总结时携带人格/用户提示词（修复记忆偏差）
- 阶段总结的 LLM 输入现在包含当前会话配置的人格设定与用户提示词（`_conversation_prompt_text`），
  LLM 可据此正确理解双方身份、称呼与关系背景，再结合对话内容总结，减少张冠李戴与设定误判；
  模板新增规则：参考设定仅用于身份理解，禁止把设定中未发生的事写成记忆。

### 3. 群聊按事件数触发总结（修复 all 模式不总结）
- 群聊消息彼此不构成「轮」（连续用户段只算 1 轮），导致 all 模式下轮数永远不涨、无法触发总结；
  现改为群聊按「事件条数」计数触发（默认阈值与私聊一致，可配置）。

### 4. 重复人物关系去重
- 身份记忆改为按「人格 + 用户」幂等沉淀（跨作用域只保留一条），不再依赖内容指纹；
- 默认身份记忆模板移除时间戳（时间仅记录在元数据），避免同内容因时间不同反复新建；
- 总结写入前做内容指纹查重，与库内同指纹记忆合并，不再每次总结都堆叠重复关系；
- 总结提示词新增去重规则：无新事实/新关系变化时不输出 relationship 型记忆。

### 5. 去除与示例插件的雷同实现
- 移除与示例插件逐字相同的全局桥接变量声明 `_ACTIVE_BRIDGE`，改为类属性 + 独立注释；
- 桥接入口 `get_deepmemory_bridge` 重构（main 提供实现、core.bridge 延迟再导出）；
- 重写 `deepmem_remember_tool` 的 docstring 与措辞；
- 注释雷同扫描（vs 三个本地示例插件）由 1 处降为 0 处。

### 6. 默认值与文档
- `capture.group_capture_mode` 默认值由 `related` 改为 **off**（群聊默认不捕获不总结）；
- 新增 `summary.group_enabled`（默认 **False**，群聊阶段总结独立开关，配合非 off 捕获模式使用）；
- README 新增「与陪伴插件（为你续写的故事）联动注意事项」：
  **连接联动插件并开启消息拟人化托管时，务必把群聊捕获设为 off**，否则两个插件会同时沉淀群聊记忆造成重复错乱；单独使用或未开启联动托管功能时不作要求。

## 说明

- 已有部署中，若用户曾在设置页保存过 `group_capture_mode` 旧值，需在设置页手动改回 off 或所需模式；
  其余新默认值（群聊总结开关等）对未保存过的项自动生效。
- 桥接接口调用方式不变：`from astrbot_plugin_deepmemory.core.bridge import get_deepmemory_bridge`。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_deepmemory_alpha-0.54`。
