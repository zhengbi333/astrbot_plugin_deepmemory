# alpha-0.60（2026-08-08）

## 变更

- **修复群聊 all 模式总结输出「没有值得保留的长期记忆」**：
  - 根因：群聊总结规则（related 模式专用）只允许提炼与机器人相关的信息，all 模式下成员间的讨论被 LLM 判定为「无新信息」；
  - 修复：总结附加规则按捕获模式区分——all（全员捕获）模式使用旁观者视角，允许提炼成员间新出现的约定、事件、事实、关系变化、日程等公共信息；related 模式维持原规则；
  - 兜底：LLM 输出「没有新信息/未参与互动/没有值得保留的记忆」类总结时，**不再写入垃圾记忆**，仅将对应时间线标记为已总结（不重复花 token 重试）。
- 图片/媒体消息进入时间线：上一版（alpha-0.59）已修复空文本命令误判 + 新增私聊通用捕获入口，本版未改动；请重载后实测。
