# alpha-0.37（2026-08-08）

## 修复

- **系统通知消息（退群等）改为「时间线可见但不计入未总结」**：
  - 时间线新增 `is_system` 标记：退群、入群、撤回、拍一拍等系统/状态通知仍显示在时间线（标记「系统通知」），但不计入未总结轮数、不参与总结、也不被 /reset 清理。
  - 旧库自动迁移：启动时把已捕获的系统通知事件标记为 is_system（保留显示）。
  - 轮数/总结/待总结统计均排除系统通知。

## 变更

- **身份记忆内容模板可配置**（设置 → 记忆捕获 →「身份记忆内容模板」）：
  - 默认模板：`{user_name}在{time}给我发了消息`（事实陈述，无「很熟」误导）。
  - 可用占位符：`{user_name}` 用户昵称、`{time}` 本地时间、`{user_id}` 平台 ID、`{platform}` 平台名。
  - 替换旧模板「X 告诉过我他的名字，我们互相认识」。
- **调试页人格解析说明补充**：会话未绑定人格时显示提示——「如需会话级绑定：AstrBot WebUI → 会话管理 → 打开该会话详情 → 设置人格」。

## 说明

- 会话级人格绑定位置（已从 AStrBot 源码确认）：AstrBot WebUI → 会话管理 → 会话详情（dashboard 的对话信息更新接口 `persona_id`）。未绑定会话时插件自动跟随全局默认人格。
