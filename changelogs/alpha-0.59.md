# alpha-0.59（2026-08-08）

## 变更

- **修复图片/表情等媒体消息不进入时间线**：
  - 根因一：空文本消息被 `looks_like_command` 判为「命令」（空文本返回 True），主链与群聊捕获均把
    纯图片/表情消息当作命令跳过；
    修复：空文本不再判为命令（媒体消息正常走捕获）。
  - 根因二：插件没有私聊消息捕获入口——文本私聊依赖主链（on_llm_request），而**不触发 LLM 回复的
    消息（如纯图片）完全没有入口**；
    修复：新增 ALL 消息捕获过滤器（`handle_message_capture`，priority 1500），私聊消息统一捕获，
    与主链捕获通过 message_id 去重（去重逻辑收敛到 `capture_timeline` 统一生效）。
  - 兜底：关闭「多模态内容描述」时，媒体消息仍写入基础类型标记（`[图片]`/`[文件]` 等），不会因无描述被过滤；
    图片理解/文档摘要超时由 45s 收紧至 20s，避免主链路径被长时间阻塞。

## 说明

- 专项验证：私聊纯图片（含关闭描述时的标记）、统一去重、私聊文本、群聊不重复捕获；完整回归通过。
- 版本备份：工作区 backup 目录下的 `astrbot_plugin_deepmemory_alpha-0.59`。
