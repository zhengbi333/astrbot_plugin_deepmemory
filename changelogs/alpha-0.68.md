# alpha-0.68（2026-08-08）

## 变更

- **最短记录字数默认值统一为 1**，并明确两项配置的管辖范围（设置页提示同步更新）：
  - `capture.capture_min_chars`（默认 1）：仅作用于**用户消息**——不足该字数不进入时间线
    （过滤「嗯」「？」等无意义短文本，防噪音），不影响 Bot 回复；
  - `capture.bot_min_chars`（默认 1）：仅作用于 **Bot 回复**——不足该字数不进入时间线
    （建议保持 1，短回复是「轮」的组成部分，丢失会导致轮数停滞），不影响用户消息。
- 服务端兜底默认值同步为 1（未保存配置时行为一致）。
