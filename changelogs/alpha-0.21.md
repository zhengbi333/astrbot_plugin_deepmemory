# alpha-0.21（2026-08-08）

## 修复

- **设置保存后立即回归默认值**（深入排查）：
  - 已确认磁盘配置文件本身有值（`embedding_enabled: true`），但 UI 显示"关"——说明读取链路与 AstrBot 配置系统之间存在不一致。
  - 本次整改：
    1. 兼容 AstrBot 传入的 `AstrBotConfig` 对象（非 dict）安全转 dict，避免 `dict(config)` 得到空配置导致全部回退默认值。
    2. 配置读取改为「内存优先 + 文件 mtime 变化才刷新」，保存后立即在页面回显新值；多实例下其他实例保存时也能感知。
    3. **写盘失败不再静默**：主配置文件写入失败会返回明确错误（前端提示），同时自动回退写入插件数据目录的备用配置文件 `runtime_config.json`（AstrBot 不干预插件数据目录），保证设置一定可持久化；读取时依次合并主配置文件与备用文件。
    4. 配置页接口新增诊断信息：配置文件路径与是否存在，便于定位。

## 说明

- 若保存仍失败，页面会直接提示"写入磁盘失败"及原因；日志中也会记录 `保存主配置文件失败` 的具体异常。
- AstrBot 插件配置页与深忆 WebUI 设置页共用主配置文件，建议只在一个界面修改。
