# alpha-0.92 · 2026-10-06

## 修复与维护

- 修复没有用户/群/会话归属的私聊和群记忆向同人格其它会话开放的问题。
- 增加平台隔离，避免不同平台使用相同用户 ID 时串读记忆。
- 修复桥接传入 `SessionContext` 对象时归属被静默丢失的问题，并拒绝无效会话上下文写入时间线。
- 将时间线的重复检查与写入放入同一存储锁，按会话、消息 ID、角色原子去重，同时保留用户和 Bot 两条事件。
- 修复编辑记忆后内容指纹不重算、检索访问计数重复增加、分页负值/超大值和衰减参数越界问题。
- 删除用户时按平台清理私聊记忆和未总结时间线，避免删除后被后台总结重新写回。
- 限制页面导入只能读取插件 `imports` 目录；备份文件名增加微秒；JSONL 导入扩展名大小写不敏感。
