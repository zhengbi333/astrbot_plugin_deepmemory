# alpha-0.56（2026-08-08）

## 变更

### 1. 群聊总结面板统计与触发逻辑一致
- 此前「未总结轮数」按对话轮统计，群聊消息彼此不构成轮，导致 all 模式下时间线积累大量消息而面板轮数不涨、看似不会总结；
- 现在群聊未总结量按「事件条数」折算进轮数（与群聊触发逻辑一致），面板可直观看到累计进度。
- 注意：群聊总结仍需在设置页开启 `summary.group_enabled`（默认关闭，需配合 `capture.group_capture_mode` 非 off）。

### 2. 记忆列表排序修正
- 记忆库默认排序由 `updated_at DESC` 改为 `occurred_at DESC`（按记忆发生时间，不受访问/编辑刷新影响，顺序稳定）。

### 3. 识别并跳过陪伴插件（我会永远陪着你）的主动消息
- 根因：陪伴插件主动消息使用合成事件（sender 为会话键、消息 ID 带 `private_companion_` 前缀），此前被当作真实用户消息捕获进时间线，表现为「主动消息被强制注入、显示未总结」；且总结时无用户消息，LLM 把机器人主动说的话误判为用户所说（人物关系颠倒）；
- 修复：识别合成/主动事件（唤醒标记、sender 与会话键相同、合成消息 ID 前缀），在主链捕获、群聊捕获、Bot 回复捕获三处入口跳过。

### 4. 多模态内容进入时间线
- **图片/表情包**：提取图片与表情组件，优先复用 AstrBot 已生成的图片描述（群聊上下文注入的 `[Image: 描述]`），未命中时由视觉模型生成一句话描述，写入时间线为 `[图片] 描述`，正常参与轮数与总结；
- **网址**：完整保留在时间线文本中（是否存入记忆由总结 LLM 判断）；
- **文本类文档**（txt/md/json 等）：读取内容（上限可配，默认 2 万字符）交给 LLM 生成摘要，写入 `[文件] 名称：摘要`；
- **视频/语音**：记录文件名与类型标记（视频内容理解需额外依赖，暂不实现）；
- 新增配置（capture 模块）：`media_describe`（多模态描述开关）、`media_describe_provider_id`（理解模型，留空用总结主备链）、`media_describe_prompt`（图片描述提示词）、`media_document_max_chars`（文档摘要上限）。

### 5. 修复桥接接口文件结构损坏（重要）
- `core/bridge.py` 中 `get_deepmemory_bridge` 函数此前误插入类定义中间，导致 `DeepMemoryBridge` 类只剩 `__init__`、其余 28 个方法全部落入函数体（模块可导入但桥接接口全部不可用）；
- 已重构：类方法回归类定义、函数移至文件末尾，桥接接口（add_memory/search/record_bot_action 等 29 个方法）恢复完整。
