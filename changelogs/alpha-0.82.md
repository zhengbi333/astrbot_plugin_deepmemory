# alpha-0.82 · 2026-10-02

修复桥接上下文隔离与混合检索错位。

- `SessionContext.from_dict` 从 AstrBot 会话键补全平台、作用域、私聊用户及群 ID，减少外部调用方字段遗漏。
- 最近记忆读取增加人格及群归属约束；群记忆按群共享，避免被当前发言人的 user_id 误筛掉。
- 时间线聊天读取必须有会话；只有 user_id 的调用不再退化为全库；人格缺失时使用已解析会话的缓存，否则保守返回空。空上下文保留管理面板全局视图。
- 可见性校验不再因缺少当前人格/用户/群信息而放行；旧记录缺少归属 ID 时用来源会话阻止越界。
- 向量召回在截断 `embedding_top_k` 前先过滤不可见记录，防其他人格或用户的高相似记录挤占可见候选。
- Rerank 按文档 index 回填分数，校验重复/越界索引及非有限数；乱序结果不再错配原文档。

根因：桥接参数规范化缺失，列表/时间线绕过了检索器的可见性约束，向量先截断后过滤，重排分数按返回顺序分配。

验证：真实 SQLite 多用户、多人格、群共享与向量召回边界；运行数据库只读快照的原 11 项真库测试（测试写入仅发生在临时副本）。与 storyteller 联合回归结果见工作区 `AUDIT_REPORT.md`。

数据兼容：没有变更数据库结构，没有迁移、删除或改写历史记忆。未解析身份的聊天调用会保守减少素材，后台管理全局视图保持可用。
