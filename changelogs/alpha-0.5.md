# alpha-0.5（2026-08-07）

## 新增

- 外观系统升级为「完整主题引擎」：
  - **明暗模式切换**：跟随系统 / 明亮 / 暗色，像系统主题一样一键切换整个界面的明暗基调；侧边栏、卡片、选项框、输入框、文字颜色全部联动。
  - **8 套完整配色主题**：紫罗兰（默认）/ 晨曦青蓝 / 晚樱粉 / 竹青绿 / 琥珀橙 / 暗夜靛 / 月光净白 / 墨黑纯暗。每套主题自带明亮与暗色两套变量（底色、卡片、边框、文字、强调色），不再只是改强调色。
  - 主题卡以「亮色 + 暗色」双色点展示；自定义主色 / 辅色 / 背景板颜色仍可作为覆盖项。
  - 明暗模式或系统主题变化时（`onContext`）自动重新应用外观。
- 外观配置新增 `scheme` 字段（auto / light / dark），随外观一起保存与恢复。

## 修复

- 侧边栏、选项框等元素不跟随主题的问题：此前只覆盖了强调色与页面底色，现在整套 CSS 变量（`--bg-elev` / `--bg-soft` / `--border` / `--text*` / 玻璃变量）均由主题引擎注入，所有控件自动联动。

## 说明

- 旧版已保存的外观配置（无 scheme 字段）自动按 `auto` 处理，无需迁移。
