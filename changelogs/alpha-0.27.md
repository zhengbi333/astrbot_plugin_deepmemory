# alpha-0.27（2026-08-08）

## 修复

- **调试页三环诊断数据新旧混杂**：
  - 根因（前端缓存）：设置页与调试页共用 `loadSettings` 的缓存守卫（`state.settingsSchema` 存在即不重新请求）。保存后只更新了页面渲染值（values），而「磁盘快照 / 插件内存值」（configDiag）仍是旧快照，导致三环显示互相矛盾（如磁盘 true / 读取 false / 内存 true），重载后才一致。
  - 修复：`loadSettings` 支持强制刷新；调试页每次进入强制重新拉取配置快照；设置页保存成功后也强制刷新，三环数据同步更新。
