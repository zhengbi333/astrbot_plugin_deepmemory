# alpha-0.70（2026-08-08）

## 变更

- **修复命令消息被捕获进时间线**：
  - 根因：AstrBot 在消息解析阶段剥离命令前缀（`/reset` 在事件文本中只剩 `reset`），
    命令判定仅按解析后文本判断导致误判为普通消息，命令（如 /help）被捕获进时间线；
  - 修复：命令判定同时使用原始消息文本（`raw_message` 的 `raw_message`/`raw_text` 字段，
    保留完整前缀），主链捕获、群聊捕获、通用捕获三处入口统一生效。

## 说明

- 版本备份：工作区 backup 目录下的 `astrbot_plugin_deepmemory_alpha-0.70`。
