# alpha-0.78

## 设置页改为自动保存（与陪伴插件一致）

- 原「修改后点保存按钮 + 红色警示条」改为**修改即自动保存**（`data-skey` 控件 change / 开关点击 → `saveSettingsKey` 单键保存 → 刷新配置快照，保留模块折叠状态）；
- 移除模块级「保存」按钮，仅留「恢复默认」；顶部警示条改为绿色说明「设置修改后自动保存」；
- 布尔/整数/小数/文本/下拉（含 provider 分类列表）全部走类型转换与后端 `config/module/update`；
- 静态结构验证 `verify_dm_settings.js` 10 项全过。

## 记忆膨胀与检索性能修复（用户要求压测任务）

- **压测数据（128 维向量、bench_memory_pressure.py）**：
  - 旧路径（全量读取所有向量再机械截断）：1k=66ms / 10k=697ms / 50k=3710ms —— **延迟随记忆总量线性增长（实锤）**；
  - 新路径（预池有序截断 limit=800）：66 / 111 / 234ms —— 50k 时**快 16 倍**且与总量解耦。
- **修复**：`iter_memory_embeddings(provider_id, limit, pool_first)` 改为按 **重要度 DESC、创建时间 DESC 有序截断**，检索读取行数恒定在候选池规模；低重要度旧记忆仍由 FTS/关键词通道兜底召回（不再机械按插入顺序截断）。
- **衰减默认 `compress` → `archive`**：归档后不再计入激活记忆，长期使用记忆条数不再无限膨胀（归档可在维护页恢复；可选手动 delete 更激进）。
