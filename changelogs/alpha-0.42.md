# alpha-0.42（2026-08-08）

## 新增

- **时间线记录记忆库操作（红字，不卡未总结）**：
  - 记忆库的导入、导出、批量/单条删除、修改、手动新增会在时间线写入操作记录（`[记忆库操作] ...`），内容红字显示、状态标记「记忆操作」。
  - 操作记录标记为系统级（is_system），不计入未总结轮数、不参与总结、不影响 /reset 清理。
  - 时间线新增长度/类型标记字段（kind：system / op / 普通）。
- **时间线多选删除**：与记忆库一致的多选模式（复选框 + 全选 + 批量删除），支持单选删除；对时间线的删除操作不会被时间线自身记录。

## 变更

- **人格沉淀词默认模板**改为：「{user_name}在{time}给我发了消息。这条消息旨在说明你知道对方叫{user_name}，与亲密度、互动等无关。」（避免模型把「知道名字」误读为熟悉关系）；已同步更新当前运行配置。
