# alpha-0.26（2026-08-08）

## 新增

- **新增「插件调试」选项卡**（侧边栏「日志」与「设置」之间）：
  - 系统信息：插件版本、数据目录、数据库路径、记忆总数、待总结轮数、上次维护时间。
  - 配置一致性诊断：磁盘文件值 / 插件读取值 / 插件内存值三环对照（原设置页的配置诊断迁移至此）。
  - 总结模型诊断：一键测试总结调用链（原总览页的总结诊断迁移至此）。
  - 所有测试/调试类 UI 集中于此，正式发布时移除该选项卡即可保持其他页面干净。

## 变更

- 设置页移除「配置诊断」卡片，总览页移除「总结模型诊断」卡片，保持面向用户的功能页面整洁。
- `runtime_embedding_enabled`（插件内存值）与页面渲染值改为同一数据来源，避免环节间不一致的误报。

## 说明

- 配置保存链路经真实环境验证自洽（磁盘=读取=内存一致）；此前「不一致」为旧插件实例或浏览器缓存所致，重载插件并强制刷新（Ctrl+F5）后应恢复正常。
