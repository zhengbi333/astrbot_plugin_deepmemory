# alpha-0.52（2026-08-08）

## 新增

- **群聊捕获模式**（设置 → 记忆捕获 →「群聊捕获模式」，默认 `related`）：
  - `all`：捕获全部群聊消息（原行为）；
  - `related`（推荐）：只捕获与机器人相关的群聊消息（提及/回复/直接对话），拟人视角——Bot 不会像摄像头一样记录群聊每条无关闲聊；
  - `off`：不捕获群聊。
- **群聊总结强指令**：总结提示词在群聊时追加规则——
  - 成员之间互相讨论属于旁观背景，禁止写成「问我/对我说/向我提问」；
  - 只有直接与机器人对话的内容才允许用「对我说/问我」；
  - 总结只提炼与机器人相关的信息（被委托的事、承诺、日程、直接互动），成员纯闲聊不写入记忆。
- **群聊捕获去重**：同一消息（message_id）在群聊捕获与主链捕获之间只记录一次。

## 说明

- 不同群聊的隔离一直存在：时间线按「平台:GroupMessage:群号」独立、记忆按 `group_id` 隔离（`cross_group_visible` 默认关闭），不同群不会混在一起。
