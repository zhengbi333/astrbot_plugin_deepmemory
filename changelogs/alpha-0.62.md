# alpha-0.62（2026-08-08）

## 变更

- **修复「未总结事件」统计包含记忆库操作日志**：
  - 根因：`store.stats()` 的未总结计数只按 `summarized=0` 过滤，未排除系统标记事件
    （`[记忆库操作]` 等 `is_system=1` 日志），导致时间线页「未总结事件 n 条」偏大；
  - 修复：统计查询补充 `AND is_system=0`（与未总结列表查询保持一致）。
- 说明：系统操作日志在时间线可见（红字标记），但不参与轮数/未总结统计与总结。

- 版本备份：工作区 backup 目录下的 `astrbot_plugin_deepmemory_alpha-0.62`。
