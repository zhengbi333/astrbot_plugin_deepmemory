# alpha-0.34（2026-08-08）

## 修复

- **群聊记忆总结说话人混淆**：
  - 总结输入按行标注说话人（优先昵称、缺失用 ID），并强化群聊按人区分。
  - 提示词新增规则：对话可能包含多位不同的人，总结必须严格按说话人区分，禁止张冠李戴。
  - 群聊总结记忆改为群公共记忆（不归属触发总结的单个用户），避免归属错乱。

## 变更

- **移除「默认记忆分区 ID」（default_persona_id）配置**：严格按 AstrBot 当前会话人格隔离；会话未配置人格时统一使用固定兜底 `"default"`（不再暴露可配置项）。
- **每日减权衰减（可开关）**：`decay.daily_decay_enabled` 开启后，每条活跃记忆重要度按 `importance × (1 - rate) ** 天数` 逐日下降（记录 last_decay_at）；低于 `decay.decay_importance_threshold` 时按衰减方式归档/删除。维护页新增「立即执行衰减检测」按钮（`POST /maintenance/decay`），「立即维护」也会执行每日减权。
- **调试页新增「最近发送给 LLM 的 Prompt」**：显示最近一次总结/衰减实际发送给模型的完整 prompt（含时间、来源、Provider、字数，不截断）。
- **新增「特别鸣谢」选项卡**：预留空内容页面。

## 说明

- 旧配置文件中的 `default_persona_id` 字段不再被读取，无需清理。
- 多个人格场景：总结严格写入当前会话人格；如需排查，可在插件日志查看 `触发阶段总结: ... persona=...`。
